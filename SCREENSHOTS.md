## Как вставить

В `REPORT.md` для каждого рисунка замени строку `> INSERT SCREENSHOT ...` обычной Markdown-картинкой. Например для первого:

```markdown
![Figure 1. Home page in dark mode.](screenshots/final-home-dark.png)
```

Не ставь эту строку внутри блока кода в самом отчёте: иначе GitHub покажет текст вместо изображения. Подписи Figure 1–8 уже написаны; оставь их. Для остальных используй соответствующий номер и имя файла из таблицы.

Если переносишь отчёт в Word, вставляй каждую картинку на место соответствующего INSERT SCREENSHOT и оставляй готовую подпись. Перед сдачей проверь, что все восемь изображений видны и заглушек больше нет.
